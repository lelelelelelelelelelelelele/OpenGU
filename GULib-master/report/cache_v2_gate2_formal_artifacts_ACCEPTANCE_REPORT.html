验收矩阵

验收项结论证据
Cache ownership通过formal Cache 模块无 experiment/dataset/selector/evaluator/Torch/PyG/OGB/download import。
Score通过v1 Recipe 与 deterministic ordered ranking/scores payload；finite/identity 校验。
Prediction通过三组 N×C logits、labels/masks/classes/selection context；依赖 Selection。
Evaluation通过metric name/version/parameters Recipe；canonical JSON；依赖 Prediction。
HIT / MISS通过warm HIT store 文件完全不变且 producer=0；clean MISS producer=1。
Integrity / conflict通过三类型 corruption、marker、quarantine、父依赖实际字节递归校验。
Runner / AutoReport通过selection-only、attack-only、complete、failed:collateral 与 provenance 回归保留。
Gate 3 / Gate 4未完成四 Artifact full old/new comparison 与真实 GU/GPU canary 不在本分支。

职责与执行流

Experiment / GU producer
生成 Score、Prediction 或 Evaluation typed payload
→
Cache V2 exact boundary
Recipe / resolve / typed validation / immutable store
→
Artifact DAG
Selection → Prediction → Evaluation；递归 integrity
Fail-closed 规则：冲突、损坏、无效状态或依赖异常都不能伪装成 MISS，也不会触发 producer 重算。
