6. 机器契约与实现边界

Recipe

dict key 顺序无关；list/tuple 保序；float、Path、Enum 与 Unicode 稳定规范化。NaN/Infinity、set、非字符串 key、未知类型与实验 ownership 字段拒绝。

Header 与 producer

ArtifactHeader v1 只含 metadata，不含 payload。Producer 同时支持 semantic version 与 source fingerprint。

状态与冲突

同 Recipe + 同 content 幂等；不同 content 记录 conflict，正式 Artifact 不覆盖，Resolver fail closed。

DDL

schema v1 包含 schema_meta、artifacts、dependencies、consumer_refs、legacy_sources、artifact_conflicts。

包位置：实现采用顶层 cache_v2/，避免 attack/__init__.py 的实验配置 argv 解析污染独立 CLI，并保持 runner 与旧查询路径零改动。

8. 后续阶段门

  1. 新计算只写 V2：先补齐 payload、header 与 conflict resolution；不双写 Legacy。
  2. 新旧结果对照：Selection 序列精确比较；Prediction 使用明确浮点容差。
  3. runner 切换 V2：先小范围 canary；查询失败不得静默回退 Legacy。
  4. Legacy 冻结：保持只读、保留回滚窗口、列出未迁移 Artifact。
  5. 归档或删除 Legacy：迁移覆盖率、consumer refs、一致性和回滚备份全部通过后另行授权。

runner 切换前的硬门槛：当前有 conflict 记录和 fail-closed 行为，但尚未实现人工裁决后的可审计解除机制。

仍未完成：真实 Cora Selection cold miss → warm hit、producer 哨兵、正式 payload/header store 验收、conflict resolution、runner 接入以及任何 Legacy 冻结/归档/删除。SSH Gate 1 通过不等于“Cache 已被真实计算命中”，更不等于 Legacy 已可删除。
