# Progress Reports

This folder is a chronological archive for progress reports, checkpoints, and
presentation deliverables.

It is not the project planning/MOC hub. Use the sibling
[OpenGU DocMap](../../../../OpenGU-DocMap/_文档地图.md) for document navigation
and `self/dashboard/WORKPLAN.md` for the current operational state.

New report convention:

- `YYYY-MM-DD_short-topic/` for a report bundle with figures, slides, or assets.
- `YYYY-MM-DD_short-topic.md` for a single markdown report.
- Keep loose planning notes and document maps in the sibling OpenGU DocMap.

Start from [_Home.md](_Home.md) for the current chronological index.
