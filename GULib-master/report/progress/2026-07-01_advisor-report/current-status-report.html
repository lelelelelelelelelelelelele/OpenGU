1. 今天要讲的结论

Thesis

现在不要讲成“某个 informed selector 最强”。更稳的口径是： 我们完成了一个可审计的 GU 删除攻击实验系统，发现不同 GU 方法、 selector 和 budget 呈现强烈异质性；selector 失配本身也是 Vulnerability Fingerprint 的一部分。

2. 三段故事线

Narrative

5 月：先让系统可信

NeurIPS push 的核心不是单个结果，而是修复 pipeline 风险： train-before-select、cache key、失败结果污染、seed/path 一致性、 canonical runner 和 gate。没有这一步，后面重跑只会制造更多脏数据。

6 月：数据复盘改写重心

干净数据显示，degree/PageRank 在不少场景下强于 TracIn/IM/Hybrid。 原 selector-centered 叙事不稳，需要降级为诊断轴，而不是主贡献。

7 月：把证据链清干净

现在的问题不是有没有数据，而是哪些可作为论文证据。 dashboard 已经拆出 produced、usable、rerun，下一步按这个账本清理。

4. 关键判断

Decisions

Rebuttal-prep 不大幅换 thesis

当前是已提交、等 review。短期内不把论文改成另一篇； 主 thesis 收束为 audit、heterogeneity、fingerprint。 更激进的 reframe 留给不中后的重投版本。

GraphRevoker 要修，不要悄悄丢

GraphRevoker 是 6-method audit 的一部分。现有退化数字不能当结论， 也不应轻描淡写写成 caveat；应修聚合器/实现问题后按 method 重跑。

IF-concordance 改变“剩余实验”的读法

重合度实验说明 deployed TracIn/Hybrid 路径不干净。 主矩阵、A5 r0.01 和 arxiv pilot 中的 TracIn 相关结果要 refresh。

dashboard 是当前证据入口

以后向外汇报实验进度时，优先引用 config inventory 的 produced / usable / rerun，而不是旧的 done-only 口径。
