# Software reports

This code repository retains implementation contracts, technical acceptance evidence and runtime report generators. Manuscripts, advisor reports, scientific analyses and their figure sources belong to the [independent private research repository](E:/project/OpenGU-research/README.md).

Research reports are edited and committed there. The [figure-source index](E:/project/OpenGU-research/report/paper/FIGURE_SOURCES.md), [Work Plan](E:/project/OpenGU-research/self/research/index.html) and [Runbook](E:/project/OpenGU-research/self/research/RUNBOOK.md) are the active research entry points. Formal YAML, Recipe, metric implementations and raw runtime evidence remain code-owned; research commits do not change their deployment identity.
