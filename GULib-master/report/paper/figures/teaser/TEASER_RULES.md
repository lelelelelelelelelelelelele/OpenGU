# OpenGU F01 / teaser 后续修改规则

记录日期：2026-10-25。来源：用户转述学长的审图要求，并明确要求记录为未来修改规则。

本次只新增规则，保留上一个已展示的试版及其报告、源文件和导出文件；不立即改图。

## 1. 箭头头部与连线终点对齐

- 学长指出导出图中箭头头部相对线段末端存在后退或偏移。这是收到的审图意见，本次不将其写成已经定位到根因的导出故障。
- 后续每次修改和导出，都要放大检查最终 PDF：箭头尖端位于预定连线终点，线杆连续接入箭头头部，不能出现头部后退、断开或线杆越过尖端的可见现象。
- 优先在可编辑 SVG / draw.io 或生成器中校正箭头位置、marker 锚点和导出设置，再重新导出，以便下次生成时保持正确。
- 按学长建议，若源端调整后最终 PDF 中仍有偏移，可直接编辑 PDF 的矢量箭头头部，将其向前移动到正确终点。保留编辑前后的 PDF，并注明进行了哪些 PDF 微调；不得用整图栅格化代替矢量交付。重新导出后仍须重新检查。
- 检查的是箭头头部与线杆自身的关系；箭头与目标图元之间为可读性预留的必要间距，应按连接语义单独判断。

## 2. 每个新版本必须导出 PDF

- 每次完成一个新的 teaser 版本，都必须同时交付可打开、已检查的矢量 PDF，不能只交 PNG 或 SVG。
- PDF 与 SVG / draw.io / PNG 使用同一版本标识；检查纸面尺寸、箭头、公式、字体、裁切和文字碰撞。
- 以最终 PDF 为导出验收依据，不能只凭 SVG 或 PNG 正常就判定 PDF 正常。

## 3. 所有文字统一黑色

- 后续修改版本的标题、正文、辅助标签、参照说明、公式和上下标统一使用纯黑 #000000；不使用灰色文字。
- 此处“都改成黑色”按全部文字执行，现有彩色或白色文字也在下一次改图时纳入检查；必要时调整文字背后的填充，以保证黑字清楚。
- 用字号区分主次；加粗、对齐和留白可辅助组织层级，不再依靠灰度降低文字存在感。
- 这条是文字颜色规则，不自动要求把非文字图元、IM / IF 填充和所有连线改为黑色；后者继续服从已确定的图形语义与配色。

## 4. 保留当前版本作为对照

- 当前保留版：selector-04-request-routes，亦即用户刚认可的“IM / IF 选择路线 + 请求文档”试版。
- 本次不覆盖、重导出或修改该版本，也不修改 selector-04-GU-merged 控制版与既有 REPORT。
- 将来依据本规则改图时使用新版本名，保留现版用于同宽比较；这次认可不等同于已替换论文正式 teaser。
- 持续遵守此前独立制图边界：图稿、生成器副本、检查与报告放在独立图稿目录；不因制作 teaser 操作 Git 或写入主项目。

## 后续每次交付前检查

- 箭头头部与连线终点对齐，并已检查最终 PDF。
- 已导出同版本矢量 PDF。
- 所有文字、公式与上下标为黑色，用字号体现主次。
- 当前保留版完整，新版另存且可同宽比较。

规则文件本身不宣称上述要求已应用到保留版；下一次改图时开始执行。
