\section{Conclusion}
\label{sec:conclusion}

We presented an audit framework for studying how strategically selected deletion requests interact with graph-unlearning methods. It separates request selection from the victim update procedure and distinguishes post-request utility, budget-matched random response, and the signed difference from full retraining on the same request. The current case studies show that these reference comparisons expose method- and dataset-dependent behavior that a single post-deletion score would not describe.

The evidence in this draft is provisional and supports scoped observations rather than a universal selector or vulnerability ranking. A complete evaluation should pair utility with request-level, prediction, and privacy diagnostics, while stating the attacker information and the limits of each metric.
