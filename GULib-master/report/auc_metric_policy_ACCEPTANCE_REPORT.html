Update-Detection AUC 数据集策略

小数据集保留 secondary AUC，大数据集通过 YAML 明确关闭；关闭不是 0，也不是失败。

验收通过
40 个相关 CPU 回归测试通过，改动文件 compileall 通过。所有 arxiv phase 配置关闭 AUC，Cora/Citeseer 主配置显式开启。

核心结果

执行

false 会在 method posterior/query 之前停止，不只是在报告层隐藏数值。

输出

attack.json::mia_auc = null，并由 _meta.json 记录 disabled_by_config。

Gate

开启时检查有限且不塌缩；关闭时要求字段为 null。

Cache

Score/Selection identity 不变；完整 run fingerprint 包含开关，开关两种结果不会混用。

YAML 契约

defaults:
  run_update_detection_auc: true   # Cora / Citeseer

defaults:
  run_update_detection_auc: false  # ogbn-arxiv

字段必须是 YAML boolean。旧配置缺省时保持 true；代码不按数据集名称或规模自动猜测。

方法覆盖

方法族处理
GIF / IDEAIF base pipeline 统一 guard；GIF 移除原先的重复 AUC 调用
GNNDeletenode/feature 内联 posterior 路径前提前返回
MEGU直接 MIA 路径前统一 guard
GraphEraser / GraphRevoker逐 shard query attack 前统一 guard

Cache 边界

对象随开关分叉？结论
TracIn / IM Score否selector 计算不受 AUC 影响
Selection否selected nodes 可继续复用
Prediction否设计上同一观测服务多个 Evaluation
AUC Evaluation是启用时才请求，并由 metric recipe/version 定义
当前完整 run是cell fingerprint 防止开/关产物冒充

Legacy ResultCache key 不扩展。旧完整结果命中时，输出层会按当前 policy 将 AUC 归一为 null；这与其待退役方向一致。
