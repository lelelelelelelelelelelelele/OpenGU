核心决策

即使批次间有少量重叠，也完整执行各自注册矩阵，不跨批次手工去重。只有身份完全相同、不可变且校验通过的 Cache V2 Score/Selection Artifact 可以精确命中复用；Legacy cache、同名路径和“参数看起来一样”都不能作为复用依据。

每个批次的状态机

INVALIDATED→REGISTERED→GATED→RUNNING→COLLECTED→ACCEPTED→PROJECTED→REPLACED→RETIRED

失败就停在当前状态。只有新证据被接受、投影已重建、旧引用为 0 后，旧 payload 才能进入另行授权的退役操作。

重叠批次规则

  1. 每个注册 outcome batch 完整运行。
  2. 不跨批次剪掉重复 cells，不复制结果凑矩阵。
  3. 每批有独立 identity、manifest 和接受结论。
  4. Cache V2 中间证据仅在完整身份精确相同时命中。
  5. Legacy cache 一律不进入新批次。

必须看结果再决定

  • E8 G3 → G4；G4 → G5。
  • arxiv feasibility → 首 seed → 扩展。
  • A3 是否有非平凡 hybrid synergy。
  • E7 transfer ratio 是否达到 60%。
  • 新证据是否改变主张、对照组或 ablation。
