# results/ Agent Guide

> 本目录只负责 SSH 回传结果在本地的落地、可信使用、整理和归档。

## 职责

- 管理已回传产物及其本地可追溯组织；实验定义、缺陷判断、远端修复和重跑不属于本目录。
- 可信验收使用 [SyncMate agent guidance](../scripts/syncmate/AGENTS.md) 拥有的合同；收到文件或进程成功不等于证据已接受。
- 保留产物的 metadata、完整 Git SHA、配置或 Recipe 身份和目录归属；不靠手工改名、覆盖或补写内容制造一致性。

## 整理与归档

- 未核验、冲突、partial、stale、corrupt 或身份不明的内容保持隔离，不进入 aggregate、报告或研究结论。
- 归档前确认批次、来源、身份、引用者和可恢复位置；存在正式消费者的路径不得为了整理而擅自移动。
- 删除、批量移动或覆盖需要当前任务对精确目标的明确授权；本地归档不授权远端删除。

## 交接

交接时只需区分：已落地、已验收、已生成可信派生物，以及仍未验证或被隔离的内容。
