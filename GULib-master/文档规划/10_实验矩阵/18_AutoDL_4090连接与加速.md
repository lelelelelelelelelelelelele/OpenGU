# AutoDL 4090 连接与加速

> 这张卡记录当前 AutoDL 4090 实例的连接事实。实例释放、端口变化、镜像重建或 SSH key 变化后都可能失效；不要把这里的 host/port 当成长期稳定配置。仓库文档不记录密码。

## 当前结论

- 当前实例可以免密 SSH 登录。
- 本机 SSH alias: `autodl-opengu`
- 快捷连接:

```powershell
ssh autodl-opengu
```

- 直连命令:

```powershell
ssh -p 22652 root@connect.bjb1.seetacloud.com
```

- 本机配置位置: `C:\Users\ADMIN\.ssh\config`
- 本机 key: `C:\Users\ADMIN\.ssh\id_rsa`
- 已验证 `BatchMode=yes` 可用，不需要密码。
- 原始直连命令只用于恢复 alias；日常实施使用 `ssh autodl-opengu`。

## network_turbo

AutoDL 学术资源加速在实例内启用:

```bash
source /etc/network_turbo
```

2026-07-09 复测确认 source 后会出现:

```text
http_proxy
https_proxy
no_proxy
```

不用时取消:

```bash
unset http_proxy && unset https_proxy
```

建议使用场景：

- `git pull` / `pip install` / 下载学术资源前先 `source /etc/network_turbo`。
- 跑实验本身不依赖代理；如果怀疑代理影响内网或本地服务访问，执行 `unset http_proxy && unset https_proxy`。

## AutoDL 控制台配置

免密登录的长期源头不是这里的端口，而是 AutoDL 控制台里的 key 配置:

- 控制台 -> 容器实例 -> 设置密钥登录
- 本机公钥: `C:\Users\ADMIN\.ssh\id_rsa.pub`
- 当前实例已经接受这把 key。

如果新开实例后 alias 失效：

1. 在 AutoDL 控制台确认新实例 SSH host / port。
2. 把本机公钥 `id_rsa.pub` 加到 AutoDL 控制台的密钥登录配置。
3. 更新 `C:\Users\ADMIN\.ssh\config` 中 `Host autodl-opengu` 的 `HostName` / `Port`。
4. 用 `ssh -o BatchMode=yes autodl-opengu "echo ok"` 验证免密。
