2. IM coverage proxy 是否只是 degree

IM 的风险是：单点 spread 可能受 degree 强烈影响，最终集合却被误写成 独立的组合覆盖信号。当前 retained evidence 在六个数据集上比较相同预算下 的 top-set Jaccard：

Dataset Cora CiteSeer PubMed Photo Computers CS Mean
IM vs degree 0.187 0.177 0.061 0.046 0.030 0.032 0.089

正确结论是：

IM 在 set level 没有退化为 degree。其组合式 coverage 在所有六个数据集上 都产生了不同节点集合，而且在较大图上的差异更明显。

不能推出：

  • IM 的 downstream attack outcome 一定强于 degree；
  • 低 Jaccard 意味着两个 selector 中有一个实现失败；
  • 单次 deterministic selector 对照已经构成跨 seed 统计显著性。

机器可读来源：summary.json。

3. trajectory influence proxy 是否对准 eval-IF

paper-aligned trajectory score 使用多个训练 checkpoint 的 evaluation-conditioned gradient inner product。它与 C-IF 的 final-state reference 比较；reference 中的逆 Hessian 项统一通过迭代 IHVP 求解。

当前隔离 gate 覆盖：

  • Planetoid Cora、CiteSeer、PubMed；
  • GCN 与 GAT；
  • seeds 2024 / 7 / 42；
  • 固定 k=7；
  • selection target 为与 candidate set 分离的 validation loss，test labels 只用于 downstream utility。
Configuration V2 vs eval-IF Spearman common@7，seeds [2024,7,42]
Cora / GCN 0.877 [5,6,5]
CiteSeer / GCN 0.950 [6,5,4]
PubMed / GCN 0.908 [5,3,5]
Cora / GAT 0.825 [6,7,5]
CiteSeer / GAT 0.962 [6,6,5]
PubMed / GAT 0.762 [4,4,1]

配置均值 Spearman 为 0.762–0.962。因此可以写：

隔离的 trajectory proxy 通常与 eval-IF reference 高度对齐，但这种对齐 依赖 dataset × backbone；PubMed/GAT 是明确的 seed-sensitive 边界。

不能写成“trajectory proxy 与 IF 等价”。尤其是 PubMed/GAT 的 common@7 降到 [4,4,1]，说明全排序相关仍较高时，有限预算集合也可能不稳定。

旧 deployed cross-final selector 与 V2 的配置均值相关方向不稳定，不能作为 这个 trajectory score 的替代证据。旧 TracIn / Hybrid artifact 只保留为 legacy 结果，不进入本节 proxy-validity 结论。

4. 与 A/B–C–D 证据的关系

本页不重复 A.6 的 IF/GIF taxonomy：

  • A/B 是 target-free parameter-change 组；
  • C 是不含 post-deletion grad2 的 eval-conditioned IF；
  • D 才是使用 grad1-grad2 source 的 graph-aware GIF；
  • trajectory proxy 在本页验证的是 eval-IF 对齐，不因此自动成为 D-GIF。

5. production 接入边界

当前 proper trajectory selector 已完成公式、独立 Recipe、跨数据集/模型 selector gate 与缩减版跨机器排序检查，但还没有完全进入 main：

待闭环项 为什么需要
正式 immutable Score Artifact/store 验证 cold miss、warm exact hit 与同 Recipe 内容冲突隔离
Legacy store 前后快照 证明新版没有读取或污染旧 IF / Selection Cache
Hybrid parent identity 确认 Hybrid 明确依赖同一个 versioned trajectory Artifact
最小 GU canary 验证 selector 能进入真实 approximate-GU 流程并生成完整 outcome
main runner / registry promotion 上述 gate 通过后才允许默认入口使用

这些属于“接入 main”的工程与 end-to-end 验收，不阻止 P1–P3 先写成 supplementary；但在它们完成前，正确名称仍是 conditional prototype，不能写 production-ready。

7. 当前最短论文结论

可以写：

IM's low set overlap with degree across six datasets shows that its coalition-level coverage proxy does not collapse to pointwise centrality. Separately, an isolated multi-checkpoint trajectory score remains aligned with an eval-IF reference across most dataset--backbone configurations (mean Spearman 0.762–0.962), with PubMed/GAT exposing a clear seed-sensitive boundary. These are selector-level validity results; formal cache integration, Hybrid composition, and graph-unlearning outcomes remain outside the present evidence boundary.

不要写：

proper-TracIn / Hybrid 已经在 main matrix 中证明 influence attack 的强弱。
