## 一句话定位

> GNNExplainer 在一个**已经训练好的 GNN**上，针对一个预测或一组预测，学习局部 computation graph 的结构 mask 和节点 feature mask，找出能够保留预测的紧凑子图/特征子集；它解释的是模型当前依赖什么，不是估计删除节点后重训或 unlearning 后模型会损失多少。

## 核心逻辑链（problem → method → validation）

| 环节 | 内容 | 证据 |
|---|---|---|
| 问题 | GNN 的预测同时依赖消息传递路径、邻居关系和节点特征；普通 saliency、全局 attention 或非图 surrogate 难以表达结构的联合贡献 | §1–2，Fig. 1–2 |
| 方法 | 在目标实例的局部 computation graph `Gc(v)` 内，学习边/子图 mask `M` 与 feature mask `F`，使 masked graph 尽量维持被解释模型的预测，同时用大小/离散性正则让解释紧凑 | Eq. (1)–(7)，§4.1–4.2 |
| 多实例解释 | 对同一类多个实例的局部解释做 relaxed graph alignment，再用 median 聚合成 class prototype | Eq. (8)，§4.3，Appendix A |
| 验证 | 合成 motif 数据有 ground truth，可算 explanation accuracy；MUTAG 与 REDDIT-BINARY 用化学基团、讨论结构和 feature heatmap 做定量/定性检查 | Table 1，Fig. 3–6 |

- 第 6 页，在“断开的边即使重要也不会被选为解释”旁写了 **`gap`**。复习时应把它理解成一个值得追问的边界：解释子图必须位于目标 computation graph 内并能把消息传到目标节点；但“没有被 mask 选中”不等于完成了训练层面的因果删除实验。

## 模块 1 · 大框架 / Motivation Map

### 作者为什么要做

- GNN 的表达力来自邻域聚合，但同一个预测可能由多条路径、多个节点及其特征共同形成。
- 解释不能只给一个全局 edge attention：同一条边对不同目标节点可能作用不同；而且 attention 还受具体 GAT 架构限制。
- 解释结果要同时回答两件事：**哪些结构路径重要**，以及**这些节点的哪些 feature dimensions 重要**。

### 最该记住的创新

1. 把“找解释”转成在目标 computation graph 内寻找一个能保留预测的紧凑子图。
2. 用一个可优化的 soft mask 近似离散子图选择，再通过阈值化得到解释图。
3. 结构 mask 与 feature mask 联合学习，而不是只给边打分。
4. 把局部解释对齐并聚合成 prototype，尝试从单实例走向 class-level insight。

### 借用的部分

- GNN 的 message-passing 抽象 `MSG / AGG / UPDATE`。
- mutual information / conditional entropy 的信息论解释框架。
- mean-field variational approximation、sigmoid relaxation、gradient descent、entropy/size regularization。
- 图匹配/对齐和 median prototype 不是全新图学习范式，而是服务于局部解释的组合件。

## 方法与公式复习

### 1. 为什么只看 `Gc(v)`

对节点 `v` 的预测，L 层 GNN 的递归邻域聚合只会使用其 L-hop computation graph `Gc(v)`。因此论文把目标实例的输入压缩为：

- `Ac(v)`：computation graph 的 adjacency matrix；
- `Xc(v)`：其中节点的 feature set；
- `Φ`：保持冻结的、已经训练好的 GNN。

解释对象是 `(GS, XSF)`：`GS` 是 `Gc(v)` 的小子图，`XSF` 是被 feature mask 保留下来的维度。

### 2. Mutual information 目标（Eq. 1–2）

$$
\max_{G_S} MI(Y,(G_S,X_S))
=H(Y)-H(Y\mid G=G_S,X=X_S).
$$

因为冻结的 `Φ` 使 `H(Y)` 为常数，优化等价于让 masked graph 上的条件熵变小：

$$
H(Y\mid G=G_S,X=X_S)
=-\mathbb E[\log P_\Phi(Y\mid G=G_S,X=X_S)].
$$

直觉不是“删除后模型重新学一遍”，而是：**只给模型保留这部分输入，它还能不能维持原来的预测概率**。

### 3. 从离散子图到可优化 mask（Eq. 3–5）

所有子图枚举不可行，因此作者把 `GS` 视作随机图，用 mean-field Bernoulli 分布近似每条边是否存在，并学习实数矩阵 `M`：

$$
A_c\odot\sigma(M)
$$

作为 masked computation graph。实际训练时对目标类别使用 cross-entropy 形式（Eq. 5），最后阈值化低权重边得到解释子图。

这里有两个重要前提：

- `M` 的参数量随 `Gc(v)` 变大，而不是随整个图的节点总数直接变大；
- 这是非凸 GNN 上的连续松弛，论文报告“常得到高质量局部最优”，不是给出全局最优保证。

### 4. Feature mask（Eq. 6–7）

结构解释不够时，再学习 `F∈{0,1}^d`，只保留少数 feature dimensions。作者用 reparameterization 和 Monte Carlo 估计让 feature mask 可反向传播，并用 `K_F` 与正则约束解释尺寸。

因此 GNNExplainer 的解释是二维的：

```text
重要的消息传递路径 / 子图
              +
这些节点上真正被模型使用的 feature dimensions
```

### 5. Multi-instance prototype（Eq. 8）

对一个类别先选 embedding 接近类均值的 reference node，再把其他实例的解释图对齐到 reference，优化：

$$
\min_P \lVert P^TA_vP-A^*\rVert+\lVert P^TX_v-X^*\rVert.
$$

最后用 aligned adjacency 的 median 形成 `Aproto`。所以 prototype 不是一次性训练出的全局 explainer；它是**先做局部解释，再做图对齐与稳健聚合**。

## 机制辨析

### GNNExplainer 是什么，不是什么

- **是**：冻结模型上的 post-hoc、target-conditioned、局部输入 mask 优化。
- **不是**：改变 GNN 参数的训练算法、unlearning 算法、节点删除影响函数，或模型因果解释的充分证明。
- **是**：寻找“保留哪些输入仍足以支持当前预测”的 sufficient-subgraph 风格解释。
- **不是**：直接估计“删掉某个节点后重新训练，validation/test loss 会变化多少”。

### Mask 权重不等于 deletion influence

GNNExplainer 优化的是当前冻结的 `Φ(A_c\odot\sigma(M),X)`；OpenGU 的 deletion/influence 问题还要考虑：

1. 图元素被删后训练样本、传播路径或归一化怎样改变；
2. 模型是否重新训练，还是经过某个 approximate unlearning operator；
3. 目标是 validation/test loss、accuracy drop、参数变化，还是 approximate-vs-retrain gap；
4. 多个元素一起删时的 set interaction。

因此，GNNExplainer mask 可以作为“模型依赖的结构线索”，但不能未经实验就当成删除排序的 ground truth。

### Embedding 是什么，不是什么

- 是 GNN message passing 后、分类头之前的节点/图表示。
- 它不是最终类别概率，也不等于 explanation prototype 本身。
- 在本篇里，embedding 主要用来找 class-level reference node；它服务于 graph alignment，不是一个独立的下游性能指标。

## 证据强度与局限

| 证据 | 它支持什么 | 它不支持什么 |
|---|---|---|
| Synthetic ground-truth accuracy | mask 能找回作者预先植入的 motif / feature signal | 不证明真实图中的唯一因果解释，也不证明跨模型/跨数据集普适 |
| MUTAG / Reddit qualitative figures | 解释模式具备领域可读性，能帮助 debug 或提出 domain hypothesis | 不提供充分的统计可靠性；示例可能是 cherry-picked |
| Table 1 vs Grad / Att | 在作者设定的 mask size、训练和 baseline 下，GNNExplainer 的 ground-truth recovery 更好 | ATT 使用单独训练的 GAT；不是同一被解释 GNN 上的完全对齐消融 |
| Multi-instance prototype | 局部解释经对齐和 median 后能形成类级结构线索 | 不能掩盖实例间邻域差异；附录承认 graph alignment 在噪声和结构方差下困难，最大公共子图相关问题是 NP-hard |
| 非凸 mask 优化 | 工程上能找到有用的局部解 | 没有全局最优或唯一性保证；结果依赖初始化、正则和阈值 |

## 模块 2 · 复习问答（本轮由标注触发，不虚构用户作答）

1. **GNNExplainer 真正在优化什么？**
   - 复习结论：在冻结 `Φ` 的前提下，学习一个结构 mask 和 feature mask，让保留下来的 computation graph 尽量维持目标预测，同时满足紧凑/离散约束。
   - 状态：已整理；锚点 Eq. (1)–(7)。

2. **为什么必须从 computation graph 而不是整张图解释？**
   - 复习结论：L 层消息传递对目标节点只会使用其 L-hop 局部计算图；在此范围内学习 mask 既保留有效路径，又把优化规模限制在局部图。
   - 状态：已整理；锚点 §3.1–3.2、Fig. 2。

3. **mask 分数能不能直接拿来做 OpenGU 删除排序？**
   - 复习结论：不能直接等同。它回答的是“模型当前预测依赖什么”；删除排序还要回答“元素被删除并重训/被 unlearn 后，目标损失如何变化”，两者的模型状态和目标函数不同。
   - 状态：核心边界已形成；锚点 Eq. (5) 与 OpenGU graph-deletion / unlearning 目标的对象不同。

4. **为什么作者用 embedding 选 reference node？**
   - 复习结论：用类内平均 embedding 附近的节点作为结构原型起点，便于把其他局部解释对齐到同一坐标；它不是说 embedding 本身就是解释。
   - 状态：已整理；锚点 §4.3、Appendix A；对应 Zotero 第 12 页评论。

## 模块 3 · 我的感悟

- **品类纠偏**：这篇不是“重要节点选择器”意义上的 deletion method，而是解释器；它在 OpenGU 里更像 terminology / representation background。
- **Sharp insight**：最可迁移的不是“GNNExplainer 比 Grad/Att 高多少”，而是把解释对象限定在目标 computation graph，并把结构依赖和 feature 依赖同时显式化。
- **对 OpenGU 的用处**：可以借用 target-conditioned computation graph、结构+特征联合分析、local explanation 与 class prototype 的分层语言；真正的 deletion/unlearning 研究仍需单独报告 retrain / operator / set interaction。
- **对 `gap` 的回看**：你的第 6 页标注提醒了一个重要分叉：消息路径上的“不可达/断开”是推理解释约束；但这仍不是训练动态或删除后模型变化的证据。
- **下一步导师追问**：如果把 mask 作为候选 selector，如何用 exact retrain 或 approximate-unlearning operator 验证它？单点 mask 是否在 set-level deletion 中保持有效？

## 模块 4 · Reviewer 评分 · NeurIPS（复盘）

**选会理由**：论文实际发表于 NeurIPS 2019；它是方法型 ML 论文，核心贡献是将 GNN 的结构化输入纳入 post-hoc explanation，而非机器人系统或工程基础设施。

**Summary**：提出冻结模型上的 model-agnostic GNNExplainer，通过结构/特征 mask 优化局部解释，并用 synthetic ground truth 与真实图案例验证。

**Strengths**

1. 问题转化清楚：把图解释写成 computation graph 上的结构化 mask 选择。
2. 同时处理 graph structure 与 node features，覆盖 node/link/graph prediction 的扩展。
3. synthetic motif、MUTAG、Reddit 形成了从可量化 recovery 到领域可读案例的证据链。

**Weaknesses**

1. 解释质量高度依赖 `K_M`、`K_F`、正则和阈值；synthetic 直接使用 ground-truth size，真实场景下的尺寸选择不够独立。
2. mask 是冻结模型上的预测保持 proxy，论文没有证明它对应训练因果、删点重训影响或唯一合理解释。
3. ATT 需要另训 GAT，Grad/ATT 的对齐并非所有实验都在同一架构/同一解释接口上完成。
4. multi-instance prototype 的 graph alignment 在结构噪声和邻域差异下仍是难点，论文自己也把它列为开放问题。

**Scores**

- Soundness：3/4
- Presentation：3/4
- Contribution：3/4
- Overall：7/10（方法影响力强，但按今天的标准仍需更严格的 faithfulness / stability / causal evaluation）
- Confidence：4/5

**Recommendation**：Accept（按当年 NeurIPS 贡献判断）；若按今天更严格的 XAI 评测标准，主要补强方向是 explanation faithfulness、stability、hyperparameter sensitivity 与 deletion/retraining correlation。

**换 venue 会怎样**：投 ICLR 也合适，但需要把信息论目标与非凸连续松弛的理论边界讲得更清楚；投 ICRA/RSS 则缺少机器人任务和真实系统验证，不应使用机器人评判轴。

## 一句话检查点

> GNNExplainer 找的是“当前模型做出这个预测时，最小而足够的图结构和特征”；OpenGU 要找的是“删除并经过指定训练/遗忘过程后，目标模型怎样变化”。两者可以互相提供线索，但不能互换证据。
