## 一句话定位

> [原文] 论文把经典 influence function 从 i.i.d. 样本删除扩展到 SGC 的节点/边删除：不仅删除候选自身 loss，还显式计算删图后消息传播与归一化变化所引起的邻域表示/梯度变化，再用 $H^{-1}$ 估计参数与验证损失变化。

> [项目映射·推断] 对“节点删除后验证损失影响”的最终标量 score，初步应映射到 **D-GIF final reference**，而不是 A、B、C-point 或 C-simple；关键理由是它包含与本项目 `grad2` 同类的删后图梯度信息。Method 伴读时需继续核对符号方向与 source 的精确集合。

## 核心逻辑链（problem → method → validation）

| 环节 | 内容 | 证据锚点 |
|---|---|---|
| 问题 | 图节点/边互相依赖，普通 leave-one-out IF 只删除一项 loss，不能表示删边/删点后邻居表示变化 | §1；§3 开头 |
| 方法 | 在凸 SGC 上把删图引起的表示替换写成“删除旧表示 + 加入新表示”，再以 influence additivity 聚合 affected nodes | Eq. (1)–(6)，尤其 Prop. 3.2/3.3 |
| 理论 | 以 one-step Newton 为中介，给出 estimated parameter influence 对 exact-retrain parameter change 的误差上界 | Theorem 4.1；Corollary A.1 |
| 验证 | 逐节点/边 exact retrain 得到实际 influence，与估计排名比较 | §5.2，Fig. 2/3 |
| 应用 | 依据 validation-loss influence 删除边/节点，并把 SGC 当 surrogate 攻击 GCN | §5.4–§5.5，Table 2/3 |

Pipeline 中真正的方法创新是“把 graph deletion 转为 affected representations 的成组替换”；用经典 IF、SGC、灰盒 surrogate 和按分数排序属于已有工具或应用层设计。

## 模块 1 · 大纲框架 / Motivation Map

### 为什么为本项目读它

1. 它是本项目 D 层最直接的一手理论邻居：说明 graph source 为什么不能退化成候选点 $g_v$。
2. 它提供一个“为何 influence 可能超过 Degree”的干净对照：同样从已有节点选择删除，但 score 同时使用特征、标签、曲率、目标 loss 和删图后的传播变化。
3. 它把三种常被混写的东西放在同一篇里：局部影响估计、exact-retrain ground truth、按 influence 选点后的攻击效果；本项目必须把三者继续分开。
4. 它的限制正好暴露 E 层缺口：逐候选局部 score 加 top-$k$ 并不建模集合交互，也不针对某个 approximate unlearning operator 的误差。

### 四个关键公式

#### 1. 普通样本删除的参数影响（Eq. 1）

$$
\mathcal I(-x_i) \approx -H_{\hat\theta}^{-1}\nabla_{\hat\theta}\ell(x_i,y_i).
$$

- $\nabla\ell_i$：候选样本对当前参数的局部推动方向。
- $H^{-1}$：把梯度方向按训练目标的局部曲率重新缩放。
- 这是参数变化向量；若要得到验证/query loss 的标量影响，还要投影到 $\nabla_\theta f(\hat\theta)$。

#### 2. 节点删除造成的图表示变化（Eq. 5）

$$
\Delta(-v_i)=\left[\hat A(-v_i)^k-\hat A^k\right]X,
$$

其中 $\hat A=\tilde D^{-1/2}\tilde A\tilde D^{-1/2}$。它显式包含：删 incident edges、度归一化改变、变化沿 $k$ 层传播。

#### 3. 完整节点删除 influence（Eq. 6，按机制改写）

$$
\mathcal I(-v_i)
=-\mathbb 1_{v_i\in V_{\mathrm{train}}}H_{\hat\theta}^{-1}\nabla\ell(z_i,y_i)
-H_{\hat\theta}^{-1}\sum_{v_j\in V_{\mathrm{train}}}
\left[\nabla\ell(z_j+\delta_j(-v_i),y_j)-\nabla\ell(z_j,y_j)\right].
$$

第一项删除候选自身的训练 loss；第二项聚合 affected nodes 在删图前后的梯度差。两项都经过同一个 final-point $H^{-1}$。

> [!important] 与本项目 `grad2` 的关系
> [项目映射·推断] $z_j+\delta_j$ 是在删除节点/边后的传播矩阵上得到的新表示；对它求梯度就是“删后图梯度”信息。因此论文没有忽略 graph source 的 `grad2` 类项。Method 伴读需要继续统一原文 removal/addition 的正负号与本项目 $q_v=\mathrm{grad1}-\mathrm{grad2}$ 的约定。

#### 4. 对目标集合的标量 score

$$
s(v;E)\approx \nabla_\theta L_E(\hat\theta)^\top\mathcal I(-v).
$$

[项目映射·推断] 这一步把 graph-aware parameter change 投影到 validation/query loss，因而对应 D 的 eval-conditioned final influence，而非 B 的 parameter-change magnitude。

### 预期难点

1. **三个“influence”对象混在一起**：参数向量 $\Delta\theta$、验证 loss 标量变化、最终 accuracy drop 必须分开。
2. **正负号约定**：down-weight、remove、add 与“positive influence = 删除后 loss 增加”的排序方向要逐式对齐，不能只凭名称判断。
3. **source 边界**：affected nodes 的范围由 SGC 层数决定；这与本项目固定 two-hop affected set 不是自动等价。
4. **SGC 保证不能平移到 GCN**：严格凸、可逆 Hessian 与理论误差界在非凸 GCN 上不成立；灰盒攻击成功是经验 transfer，不是理论 transfer。
5. **逐点线性化到集合攻击**：原文使用 influence additivity/cumulative deletion，但 top-$k$ 同时删除存在交互，尚未形成 E 层 set-level objective。
6. **exact retrain 的角色**：它在 §5.2 是 ground truth，在攻击实验中又用于测删图后的真实性能；它不是 influence score 本身，更不是 approximate GU。

### 初步回答本项目五个核心问题

1. **score 映射哪一层？**
   - [项目映射·推断] 参数影响向量本身是 graph-aware 的 $H^{-1}q_v$；投影到 validation loss 后是 **D-GIF final reference**。
   - 不是 A=`||g_v||`，不是 B=`||H^{-1}g_v||`，也不是只含候选/删前邻域的 C-point/C-simple。

2. **是否考虑 graph source 的 `grad2`？**
   - [原文] 是。Eq. (5) 先构造删节点后的归一化传播矩阵，Eq. (6) 再使用 affected nodes 的新旧表示梯度差。
   - [项目映射·推断] 这与 `grad1-grad2` 的机制同类，但还需核对符号、affected-set 与 loss aggregation 的实现细节。

3. **exact retrain、影响估计、攻击评估是什么关系？**
   - influence estimate：不为每个候选重训，用局部 IF 预测参数/目标 loss 变化。
   - exact retrain ground truth：§5.2 删除一个元素后重训，用于检验估计排序，Spearman 报告为 0.847–0.981。
   - attack evaluation：按估计 score 累积删点/边，再训练/评估 SGC 或 victim GCN，观察真实 accuracy drop。
   - [项目映射·推断] 论文没有优化 approximate-GU-vs-retrain gap，主要测的是合法删除本身造成的 outcome。

4. **为何可能超过 Degree？**
   - [原文机制] Degree 只计结构数量；该 score 还使用特征、标签、validation target、Hessian 曲率，以及删图后消息传播/归一化变化。
   - [原文证据] Table 3 中，15% node removal 时该方法对 Cora/CiteSeer 的 victim GCN 降幅明显强于 Degree；PubMed 的优势较小，说明并非所有数据集都同样强。
   - [项目假说] 当“结构杠杆”与目标 loss/曲率错位时，D score 可能胜 Degree；当 GU approximation gap 主要由高 degree/OOD 删除驱动时，Degree 仍可能胜。这两种 winner 对应不同 objective。

5. **对潜在 E 层有什么启发？**
   - 可复用：完整 graph deletion source、以 target gradient 投影、用 exact retrain 校准局部 reference。
   - 不能直接复用：逐点 score 的简单 top-$k$、SGC 凸性保证、把删后 accuracy drop 当 approximate GU vulnerability。
   - [项目假说] E 层应把单点 $q_v$ 提升为 $q_S$ 或显式边际增益，并把真实目标换成 $F^{\mathrm{retrain}}(S)-F^{\mathrm{unlearn}}(S,M)$，即 operator-aware set objective。

## 机制辨析

### 论文 score 是什么，不是什么

- 容易误解的说法：“它就是对每个节点算一个普通 IF。”
- 订正后的机制：它先把节点删除转成候选自身 loss 删除 + affected representations 替换，再计算 graph-aware influence；投影到 validation loss 后才得到攻击排序标量。
- 证据锚点：Eq. (5)–(6)，Prop. 3.3。
- 仍不确定：原文正负号与项目 `grad1-grad2` 的逐项等价形式；待公式伴读时手工对齐。

### exact retrain 是什么，不是什么

- 容易误解的说法：“论文用 exact retrain 算 score，所以成本很高。”
- 订正后的机制：score 用 influence estimate；exact retrain 用作逐元素 ground truth 和删后 outcome 评估。
- 证据锚点：§5.2；§5.4–§5.5。
- 仍不确定：node-removal victim GCN 在每个预算点的重训/初始化细节需要结合补充材料继续核对。
